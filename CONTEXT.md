# Helios shell

Helios presents desktop activity and controls through a compact shell. This glossary names the user-visible concepts shared across its panels and system integrations.

## Language

**Media session**:
The currently selected media player together with its playback state, track position, capabilities, and controls.
_Avoid_: Player helper, MPRIS state

**Calendar**:
The merged view of events from local and subscribed calendar sources, including source-specific refresh errors.
_Avoid_: Calendar feed, calendar process

**System monitor**:
The live view of system resource usage, recent samples, and running processes available for inspection or action.
_Avoid_: System stats, process script

**Notification**:
A message received from an application that may appear as a live popup, remain in history, and offer a user action.
_Avoid_: Notify object, history item

**Bluetooth audio device**:
A Bluetooth device enriched with its connection, trust, pairing, battery, codec, and audio-profile state.
_Avoid_: Bluetooth sink, connected device
